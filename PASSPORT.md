| Projected token | Optional service-account token (configurable audience, 3600 s) at `/var/run/secrets/ego/webhook/token` |
| Filesystem | Read/write `/data` (PVC); read-only `/etc/ego` (online config ConfigMap) |
| Application roles | `admin` (full, manages role bindings, senders and revocations), `member` (read/write), `viewer` (read-only); `none` exists only as a default role (no access without a binding, cannot be put in a binding); default role `member` (`--default-role` / `EGO_DEFAULT_ROLE` / chart `auth.defaultRole`; the chart's values file states that `member` lets every signed-in organisation member read and write every tenant and names `none` for deployments with customers' tenants) |
| Role binding subjects | GitHub user login or GitHub team `org/slug`; optional per-binding agent-name scope; optional per-binding `tenants` patterns |
| Tenant model | Tenant key `<sender>/<label>`; spans sent with the shared `--otlp-token` have the bare label as key. Label read from span attribute `ego.tenant` (override `--usage-tenant-attr`) and reduced to letters, digits and `. _ - @ +` (every other character becomes `_`, at most 128 characters), so a label holds no `/`, `:`, `*`, `|` or control character, for the shared token as for a named sender; a sender's spans with no label use `default`. Session ids of a named sender are `<sender>:<label>:<name>` (`<sender>:<name>` without a label); spans for a session owned by another sender are dropped, and so are spans of another tenant of the sender for a session whose first trace named a different tenant (the tenant is stored with the archived session, so this holds after a restart). Session ownership is the sender; a session lists every tenant label on its spans, and a role sees a session when any one of its tenants is granted |
| Tenant binding | A sender token minted with `tenant` is bound to one tenant label of its sender (1 to 128 characters, exactly the alphabet above, so never `*`): on OTLP/HTTP and OTLP/gRPC every span of the export gets that label in the tenant attribute whatever it carried, applied after the export is decoded; on `/mcp` the token reads exactly `<sender>/<tenant>`. An unbound sender token labels its own spans and reads `<sender>/*`. The shared `--otlp-token` is never bound |
| Tenant display names | Table `tenant_names`: key to name (key up to 200 characters, name up to 80 characters, no control or format characters; a longer name from a sender is cut, from an admin refused). Set by an admin (`POST /api/admin/tenant-names`, or `tenantName` when minting a bound token) or taken from the span or resource attribute `ego.tenant.name` of a named sender, for its own tenant key only and only while the tenant has no name; at most 10000 names in all and 1000 per sender; the shared token and unauthenticated pushes cannot name tenants. Names are returned by `GET /api/tenants` for the tenants the caller may see and rendered by the UI as text |
| Tenant grants | Patterns `*` (all), `<sender>/*` (all tenants of a sender), `<sender>/<label>` (exact); on a role binding or on an API token (`ego auth mint-token --tenants`). A tenant-scoped role cannot use the evaluation, eval-set, rubric-set, scoring-jobs and admin endpoints and sees no data without a tenant; `?tenant=` narrows within the grant only; `GET /api/tenants` lists the caller's permitted tenants (403 to an agent-scoped role) |
| Senders | An ingest identity (id `[a-z0-9-]`, up to 63 characters) with one or more ingest tokens `egs_…`; tokens shown once at creation and stored as SHA-256 hashes (table `sender_tokens`); managed by admins under `/api/admin/senders*`. In memory per named sender: at most 5000 open sessions and 1000 tenants; a new session or tenant past the limit is dropped with a warning in the log |
